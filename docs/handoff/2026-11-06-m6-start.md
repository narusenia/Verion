# 引き継ぎ: M6（Blender 連携）の着手前

M5 は完了（Metal・Vulkan の ReSTIR と差分更新、画像一致まで済）。M6 の計画と方針を決めたところで、実装は未着手。状態の正本は `docs/implementation/M6-blender/README.md`（表の状態）。

## 決定済み（変えるときは利用者に確認）
- 結合: PyO3 で Blender と同じプロセスに入れる（`verion-py`、abi3）。対応は Blender 4.5 LTS と 5.x（ADR-0019）
- 新しい依存は PyO3・maturin・`numpy` クレートまで許可済み。それ以外は追加のたびに確認。テストは標準の `unittest`
- ライトの W は Cycles の換算に合わせる（式は項目 4 で資料と実測で確かめる）。手続き型の Sky は HDRI にベイク（ADR-0019）
- 環境光だけの Toon の段は HDRI から仮想の主光源（ADR-0020）。OIDN は CPU 版だけ同梱、GPU 版は利用者が手動で足す（ADR-0018）
- ライセンス判断は最初の外部配布の前（ADR-0004、ADR-0018）

## 開発機
- Blender: `~/Applications/Blender/stable/` の 4.5.15 LTS（Python 3.11、numpy 1.26）と 5.2.3 LTS（Python 3.13、numpy 2.3）。`Blender.app/Contents/MacOS/Blender -b --python-expr ...` で動く
- Mac は Metal のみ。Vulkan は Windows 機（RTX 3080）。main は push 済み（`fb5bc02`）
