# 引き継ぎ: M2 の残りと M3 を完了 → M4（Vulkan）へ

前の引き継ぎ（`2026-11-06-m2-after-materials.md`）の続き。M3 までは origin に push 済み。Adaptive Sampling の分は push のたびに確認する。

## 済み（この会話）
- M2: OIDN デノイズ（`verion-denoise`、実行時読み込み。CLI `--denoise`、Viewer「Denoise when done」）、StylizedSpecular の楕円・画像（手描き風）、Stylization 評価の初版（`scripts/eval_stylization.sh`）、MatCap スライダの kittest。M2 の表はすべて済
- M3: パス処理の共通化（`shaders/include/pt_core.slang`）、Wavefront（`wf_args`・`wf_extend`・`wf_shade`、キューの圧縮、間接 Dispatch）、段別計測 `--stage-timing`、メモリのメトリクス、Viewer の integrator 切替。Megakernel とビット一致
- 追加: 画素単位の Adaptive Sampling（REQ-ACC-007、ADR-0015）。両積分器で動きビット一致、`render-cli --adaptive`、EXR `SampleCount`、Viewer の Render 欄と Samples ビュー（キー 5）。等時間比較は `scripts/eval_adaptive.sh`（空の多いシーンで PSNR +2.2 dB、cornell は −1.0 dB → 既定は無効）
- 副産物: Megakernel を 1 スレッド最大 8 サンプルにして 7〜37% 高速化（画像は不変）
- 比較: Wavefront は M5 で 1.13〜1.70 倍遅い → ADR-0014 で Metal の既定は Megakernel、絶対速度目標は置かない
- 剪定: 追跡されていた `scripts/__pycache__` を外した。効果のなかった SIMD 集約の atomic は戻した

## 決めたこと
- 依存: `libloading`（ISC）を追加。OIDN は Homebrew（`open-image-denoise` 2.5.1、開発機に導入済み）。出荷時の同梱方法は配布形態の決定時
- Stylized のデノイズは Pass の入力側（Lighting AOV の放射量）を既定。出力側は比較用（`--denoise-stage output`）
- ハイライトの画像形状は Viewer でシーンの画像から選べる（新しい画像の読み込みは glTF 経由）
