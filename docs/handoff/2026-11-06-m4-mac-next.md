# 引き継ぎ: M4 の続きを Mac で

Windows 機（RTX 3080）での M4 は終わり、origin に push 済み。詳細は `2026-11-06-m4-vulkan-done.md` と `docs/implementation/M4-vulkan/README.md`（状態の正本）。Mac では次の 4 つを順に行う。

1. `git pull` して `mise run check`（CI の macOS は通っている）。Metal を `verion-gpu` の共有コード（`pack`・`readback`・`wavefront`）に置き換えたので、実機で置き換え前（`6087baf`）と画像が変わっていないことも確かめる。違えば `crates/verion-gpu-metal/src/renderer.rs` と `renderer/wavefront.rs` の差分（コミット `refactor: share scene packing…`）を見る
2. `mise run shaders` で MSL と SPIR-V を作り直す。SPIR-V のバイトは OS で違うので差分が出てよい。`mise run shaders:check` は MSL のバイト比較と、Slang ソースのチェックサム（`crates/verion-gpu-vulkan/shaders/sources.cksum`）で見る
3. Metal の画像セットを作る: `sh scripts/backend_render.sh DIR`（既定 4096 spp）。Windows 機でも同じ手順で作り、`sh scripts/backend_diff.sh REFERENCE_DIR TEST_DIR` で比べる。結果から閾値を決め、REQ-GPU-007 と M4 README の項目 9 に書く。比較は Beauty（Reference）と Stylized の出力
4. `mise run bench`。`scripts/bench.sh` に Windows の分岐を足したので、Mac の既存の基準（`apple-m5-*.json`）に対して通ること

## 補足
- 画像の一致はビット一致を求めない。比較の方式は M1 の Mitsuba 照合と同じ（`exr_diff` のチャンネル平均 1%、4×4 ブロック 2% から始める）
- Windows 機の Vulkan 側の参考値: Wavefront は Megakernel とビット一致、cube の GPU 時間 0.0506 s（Mac M5 は 0.335 s）
- SER の実験はブランチ `experiment/ser-raygen`（reorder hint が `NONE` の RTX 3080 では効果が出ず、raygen 版はドライバでハングする。ADR-0014）
- Octane は保留（利用者が環境を用意してから）
- push は毎回確認を取る
