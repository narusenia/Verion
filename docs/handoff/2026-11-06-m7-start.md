# 引き継ぎ: M6 完了と M7（NRC と Adaptive Integrator）の着手前

M6（Blender 連携）は全 17 項目が済で、完了条件もすべて入った。M7 は計画書を書いたところで、実装は未着手。状態の正本は `docs/implementation/M7-nrc-adaptive-integrator/README.md`（表の状態）。M6 の結果は `docs/implementation/M6-blender/README.md`。

## 決定済み（変えるときは利用者に確認）
- **M7 の前に画像のアルファによる切り抜きを入れる**（M7 README の A1〜A5）。IR の画像にアルファを持たせ、材質に `opacity_texture` を足し、ヒット点で UV から引いて確率的に素通しさせる（影の光線にも効かせる）。テクスチャのない材質ではコードを消す（M5 の `restirCompiled` と同じ特殊化定数）。glTF の `BLEND` と `MASK`、Blender の Principled の Alpha と Verion Surface の Opacity に対応する。Cycles との比、Blender 経由と glTF 経由の一致、Metal と Vulkan の一致、ベンチの退行なしを確かめる
- NRC のネットワーク実行は Slang の自前カーネル（ハッシュ符号化＋小型 MLP）を先にする。CUDA や Tensor は、学習が律速と測定で分かったときだけ足す。Render Graph（REQ-GPU-008）はそのとき
- NRC は選択式で既定は無効、Reference モードは通らない、有効なら非物理の印。評価で学習込みの利益が出なければ、無効のまま結果を記録して終える
- glTF 拡張への仮想の主光源の上書き項目は見送り（render-cli や Viewer で必要になったら、シーン単位の拡張として設計。ADR-0020）
- ADR-0018 の追記（Blender のアドオンは Blender の OIDN を使う）は承認済み
