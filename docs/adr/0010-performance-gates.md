# ADR-0010: v0.1 の性能は絶対目標を置かず、計測基盤とベースラインで縛る

- 状態: 採用
- 日付: 2026-11-04

## 背景

草案の 2 倍 / 3 倍は研究仮説で、根拠データがない。決め打ちの数値は表現力優先（ADR-0005）と衝突する。

## 決定

- 合格ゲート:
  - 解析解テストと Mitsuba 照合が閾値内
  - Metal GPU 計測（trace / shade / 合計）を JSON 出力し、前回比 −10% 超の退行で警告
  - 規模の下限: 5M 三角形、複数の 4K テクスチャ、M4 Pro / M5 のユニファイドメモリ内。超過は明示エラー、ストリーミングは対象外
- 規模の数値は仮置き。M1 のベンチで見直す
- 絶対速度目標は M3 の Megakernel / Wavefront 比較後に決める

## 結果

- 研究目標（2 倍 / 3 倍）は REQ-PERF-005 に Could として残す

## 追記（2026-11-04）

- v0.1 の規模ゲートは変えない（ストリーミングは対象外、超過は `Error::OutOfMemory` で明示エラー）
- ストリーミングは段階化する。Texture のみ後続で Out-of-Core を扱い（REQ-PERF-006、M10）、Geometry は全常駐のままにする
- M1 の実測: 5M 三角形・4K テクスチャ 4 枚でピーク約 4.5GB（M5）。仮置きの数値の見直しは M4 Pro の確認後
