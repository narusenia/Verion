# ADR-0009: v0.1 のスコープと実行形態

- 状態: 採用
- 日付: 2026-11-04

## 決定

- 実行形態は `render-cli` + 最小 Viewer。Viewer は累積表示・AOV 切替・Stylization パラメータ変更→再累積まで。IPR 編集は M5 以降
- 含める: 三角形メッシュ・インスタンス、Diffuse / GGX Conductor / Dielectric、テクスチャ、HDRI・Emissive・Point / Spot / Sun / Sky / Area、薄レンズ DoF、Russian Roulette、カラーマネジメント、EXR 多チャンネル AOV、P0 の Stylization ノード、デノイズ
- 外す: Motion Blur、体積、SSS、髪 BSDF、ディスプレイスメント、アニメーション連続レンダリング、Outline・顔影・髪ハイライト（Normal / Depth / ID の AOV だけは出す）
- IPR は 3 段階: M2 パラメータ再累積 → M5 差分更新エンジン → M6 Blender IPR。Scene IR に revision カウンタを M1 から持たせる

## 結果

- 外した機能は IR にフィールドを予約せず、必要時に追加する
- 草案に無かったカラーマネジメントとライト基本を M1 に追加した
