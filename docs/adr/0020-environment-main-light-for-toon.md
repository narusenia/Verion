# ADR-0020: 環境光だけで照明するとき、HDRI から仮想の主光源を求めて Toon の段に使う

- 状態: 採用（実装済み。M6）
- 日付: 2026-11-06

## 背景

太陽のない拡散した HDRI や World の背景色だけで照明すると、ToonRamp の段が出ず拡散が平らになる（`docs/specifications/gltf-stylization-extension.md` の既知の制限）。ramp の入力が、サンプルごとの cosθ × 遮蔽を寄与で重み付けして平均した値で、画素ごとの差が小さいため。Blender の新規シーンは World の背景だけで照らされることが多く、Toon 材質を付けるとまず平らに見える。

## 比較した案

- A: HDRI から支配的な光の方向を 1 つ求め、仮想の主光源にする
- B: 今のまま。利用者が主役の光を置く
- C: 環境光を複数方向（太陽と空など）に分けてスロットへ割り当てる。スロット数（4 枠）とメモリが増え、M2 で見送った方式に近い

## 決定

案 A にする。

- 方向は、環境マップの輝度（sin θ の重み付き）が上位の画素群のエネルギー加重平均で求める。群の取り方（上位何 % か）は、実装時に実画像（太陽のある HDRI、太陽のない拡散 HDRI、グラデーション、柔らかい光 1 つ）で決める
- 方向が決まらないとき（群のエネルギー加重の方向ベクトルが短い。一様な空など）は、仮想の主光源を出さない
- 遮蔽は、仮想の主光源の方向へ影の光線を 1 本飛ばして取る
- 仮想の主光源は Stylization の入力（ライトスロット）にだけ使う。物理の照明は変えない。スロットに入れる分を環境光の寄与から引くかどうかは、二重に数えないことを画像で確かめて実装時に決める
- 利用者が上書きできる: 方向、強さ、無効化。Stylization の World 設定（Blender の World タブ）として持つ。glTF の拡張には今は足さない（2026-11-06 に利用者が見送りを決定）。render-cli や Viewer で上書きが必要になった時点で、使い方を見てシーン単位の拡張として設計する。既存の glTF を壊さない任意項目の追加なので、後から足せる
- Reference モードには影響しない（Stylization は非物理の処理）

## 結果

- 検証: 太陽のない HDRI（一様、グラデーション、柔らかい光 1 つ）で段が出る。太陽のある HDRI や、点・平行光で照明したシーンの画像が変わらない
- 既知の制限（仕様書）は、実装したときに更新する
- 実装: 群は輝度の上位 1%、群の平均より上の画素だけ。強さは全天の放射照度（光の方向を向いた面）で、群だけだと柔らかい空が暗くなるため。仮想の主光源は slot 3 の環境光の代わりに入る（二重に数えない）。ビューティは変わらない（テストで確認）
