# ADR-0004: 個人研究として始め、ライセンスは保留する

- 状態: 採用
- 日付: 2026-11-04

## 背景

草案は Octane 比較を掲げるが、誰が使うかとライセンスが未定だった。

## 決定

- 個人の研究・開発プロジェクトとして始める。製品としての外部配布（オープンコア寄り）も視野に入れる。会社業務とは無関係
- Verion 自体のライセンスは M4 前後まで保留する。NVIDIA SDK 等の再配布条件が分かってから決める
- それまで、依存は商用再配布が可能なものに限り、`cargo-deny` で検査する
- ソースへのライセンスヘッダは付けない

## 結果

- オープンコアの境界（どこまで公開するか）は未決。未決事項として `overview.md` に記録する
- 判断の期限は「最初の外部配布の前」とする（2026-11-06。ADR-0018）。NVIDIA SDK は使っていないので、M4 前後を待つ理由はなくなった
