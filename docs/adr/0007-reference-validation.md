# ADR-0007: 正しさの基準は Mitsuba 3 照合と解析解テスト

- 状態: 採用
- 日付: 2026-11-04

## 背景

Reference モードは「別実装との比較」と述べるだけで、基準が未定だった。自前の CPU 参照実装は工数が大きく、バグが共通化するリスクもある。

## 決定

- 第一の参照は Mitsuba 3、補助は pbrt-v4。小さな再現シーンで FLIP / PSNR を機械判定し、CI に載せる
- 白炉テスト等の解析解テストで BSDF の誤りを外部依存なしで検出する
- 自前の CPU 参照実装は作らない。不足したら後で足す
- Stylization は物理基準がないため、別評価（REQ-QA-003）で扱う

## 結果

- glTF 材質から Mitsuba の BSDF への対応表が必要
- 閾値は初回実測で決める
