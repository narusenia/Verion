# QA 要件定義（検証）

## REQ-QA-001: 参照レンダラー照合

| 項目 | 内容 |
|------|------|
| ID | REQ-QA-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

Mitsuba 3 を第一、pbrt-v4 を補助の参照とする（ADR-0007）。小さな再現シーン（Cornell Box、球 + HDRI、GGX 金属 / ガラス）で FLIP / PSNR を機械判定し、CI に載せる。自前の CPU 参照実装は作らない。不足したら後で足す。

### 受入条件

- [ ] 閾値は初回実測で決め、記録する
- [ ] glTF 材質から参照レンダラーの BSDF への対応表がある

### 依存要件

- REQ-VIEW-001

## REQ-QA-003: Stylization 評価

| 項目 | 内容 |
|------|------|
| ID | REQ-QA-003 |
| 優先度 | Should |
| ステータス | Draft |

### 説明

物理基準がないため別評価を持つ。Art Direction 一致（影色・Shadow Band・ハイライト形状・線幅）、時間的安定性、キャラと背景・Backend・DCC 間の一貫性、追加 GPU 時間と VRAM、Toon 境界のエイリアシングとデノイズによる消失。

### 受入条件

- [ ] 各項目に判定方法とテストシーンがある

### 依存要件

- REQ-STY-007
