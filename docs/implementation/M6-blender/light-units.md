# ライトの単位（Blender の W と Verion の強さ）

Cycles との実測（`plugins/blender/tests/test_light_units.py`。拡散の白い面を各ライトで照らし、中心画素を比べる）と解析式で確かめた。

| ライト | Blender の値 | Verion の IR | 根拠 |
|---|---|---|---|
| Point | 電力 P [W] | 放射強度 I = P / (4π) | Cycles の画素値 = アルベド/π · I / d²（P=1000、d=4 で 1.2662 と一致） |
| Spot | 電力 P [W] | 同じ（円錐は点光源のマスク。絞られない） | Point と同じ値 |
| Sun | 強さ E [W/m²] | 照度 E（そのまま） | 強さ 3 で 0.7638 = 0.8/π · 3 |
| Area | 電力 P [W]、面積 A | 面の放射輝度 L = P / (π · A) | 半球への全放出が P になる。正方形・長方形・円で一致 |

全種別で Verion / Cycles = 0.972〜0.974 だった。この約 2.7% は光の単位ではなく BSDF の差（Verion は誘電体の鏡面を拡散の上に重ねる）で、Cycles の Diffuse BSDF との比較でも同じ値が出る。単位の誤りなら 3 倍以上ずれる。

## BSDF の差（参考値。項目 14）

- 粗い誘電体の拡散は、掠める角度で Verion のほうが暗い。仰角 17° の床で 9%、真上からで 2〜3%
- 床を含む実シーンの平均比（Verion / Cycles）は 0.84〜0.91（粗い誘電体 0.86、金属 0.90、発光 0.91）
- ガラス球は屈折の扱いが違い、ブロック相関が 0.84（Cycles では水平線が球の中で反転して混ざり、Verion では残る）。Verion のコアの挙動であり、アダプタでは直さない
