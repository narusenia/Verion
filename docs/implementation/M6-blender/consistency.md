# DCC 間の一貫性と Cycles との比較（項目 14）

測定日 2026-11-06。Blender 5.2.3 LTS（4.5.15 LTS も同じ傾向）、Metal。`scripts/blender_test.sh` で再現できる。

## Blender 経由と glTF 経由（合否の基準）

`plugins/blender/tests/test_consistency.py`。同じシーン（床・拡散球・金属球・Sun・Point）を、アドオンで描いた画像と、Blender の glTF エクスポータが書いた幾何・材質・カメラに KHR_lights_punctual（アドオンと同じ換算）を足して `render-cli` で描いた画像とで比べる。

| 指標 | 結果 | 閾値 |
|---|---|---|
| 平均の比 | 1.0000 | 0.97〜1.03 |
| 4×4 ブロックの相関 | 1.00000 | 0.995 超 |
| ブロックの最大差（最大値に対する割合） | 0.0001 | — |

同じ乱数列で描くため、変換が同じなら画素まで一致する。ずれたら、アドオンの変換かインポータのどちらかが変わっている。

## Cycles との比較（参考値）

どれも「Verion ÷ Cycles」。Cycles に合わせることは目標ではなく、変換の誤りを見つけるための値（許容は各テストの閾値）。

| 項目 | 平均の比 | ブロック相関 | メモ |
|---|---|---|---|
| ライト（Point・Spot・Sun・Area 3 形状） | 0.972〜0.974 | — | 床の拡散で測定。換算は `light-units.md` |
| IES（下向きの絞り） | 0.965 | 0.9996 | 1 cd を 0.0707 倍（光の強さに対して）として合わせた |
| ライトリンク（点光源） | 左 0.131 / 右 0.006（Cycles と同じ） | — | 受光側のコレクションにない球は暗い |
| ライトリンク（面光源） | Verion 0.466 / 0.018、Cycles 0.455 / 0.021 | — | 〃 |
| 拡散・粗い誘電体 | 0.858 | 0.9886 | |
| 光沢のある誘電体 | 0.888 | 0.9892 | |
| 粗い金属 | 0.899 | 0.9971 | |
| 鏡 | 0.901 | 0.9677 | |
| 発光 | 0.911 | 0.9828 | |
| ガラス | 0.902 | 0.8391 | 中実の球の屈折の仕方が違い、水平線の見え方が変わる |
| UV 付きテクスチャの立方体 | 0.839 | 0.9893 | |
| 手続き型（Checker と Math）をベイク | 0.861 | 0.9841 | |
| UDIM（2 タイル） | 色の比 0.96 前後 | — | |

材質の平均が Cycles より 10〜15% 暗いのは、Principled BSDF の層の組み方の差（Cycles は誘電体の拡散と鏡面を Fresnel で重ねて多重散乱を足す。Verion は M1 の BSDF）で、変換の誤りではない。垂直入射で約 2.7%、かすめ角で約 9% 暗い差は以前から記録してある。Octane との比較は M6 の後（REQ-ACC-002）。
