| File | Asset | Author | Use |

| `venice_sunset.hdr` | Venice Sunset | Greg Zaal | low sun, warm light, buildings |
| `studio_small_08.hdr` | Studio Small 08 | Sergej Majboroda | softboxes, product-style lighting |
| `overcast_soil_puresky.hdr` | Overcast Soil (Pure Sky) | Jarod Guest, Sergej Majboroda | overcast, no sun |

Asset pages: `https://polyhaven.com/a/<asset id>`. The md5 sums the script checks come from Poly Haven's file API.
